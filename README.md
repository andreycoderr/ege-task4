# ЕГЭ · Задание 4 — тренажёр ударений

Простой веб-тренажёр для подготовки к **заданию 4 ЕГЭ по русскому языку** (орфоэпические нормы).

Формат как в ЕГЭ: показано пять слов с проставленными ударениями, в одном — ошибка. Кликни на ошибочное.

## Запустить локально

Это статический сайт — никакой сборки не нужно. Просто открой `index.html` в браузере.

```powershell
start index.html
```

## Структура

```
index.html   — разметка
styles.css   — оформление
data.js      — словарь (~170 слов: орфоэп. минимум ФИПИ + расширение)
app.js       — игровая логика
```

Ударная гласная в `data.js` помечена заглавной буквой: `докумЕнт`, `тОрты`. Каждый раунд приложение само выбирает 5 случайных слов и в одном из них перемещает ударение на другую гласную — это и будет «лишнее» слово.

## Источник слов

За основу взят официальный орфоэпический словник ФИПИ к ЕГЭ по русскому языку, дополненный частыми словами из вариантов прошлых лет.
